~~~go
func auditDayPath(statePath, day string) (string, error) {
    parsed, err := time.Parse("2006-01-02", day)
    if err != nil || parsed.Format("2006-01-02") != day {
        return "", errors.New("invalid_audit_date")
    }
    return filepath.Join(filepath.Dir(statePath), "model-mapper-plus-audit", day+".jsonl"), nil
}
~~~
beginAudit：生成 crypto/rand ID，固定开始时间/日文件，建0700目录，以 O_CREATE|O_APPEND|O_WRONLY 打开0600文件；序列化一行、检查 short-write、Sync，成功才返回 ticket。finishAudit 只使用 ticket.Path/ID，不重新读取配置或日期。
追加及查询用同一短 IO 互斥，事件运行集合仅驻内存标记 running；不能在锁内调用管理 handler。现有文件权限核实/收紧为0600。完整行结尾必须换行；坏尾行保留、用换行分隔后续事件。
读取严格验证已知version/phase/字段、配对和重复异常；缺失文件为空，读取错误为503且受控代码。查询开始日固定，稳定逆序 started_at/id。JSON回复 Cache-Control:no-store。
