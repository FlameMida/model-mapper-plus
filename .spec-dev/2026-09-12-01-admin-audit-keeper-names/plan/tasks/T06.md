**步骤 3：最小实现**

App菜单锚点：
~~~diff
  { itemKey: 'preview', text: '规则试跑' },
+ { itemKey: 'audit', text: '操作审计' },
~~~
渲染tab==='audit'时显示AuditPanel；保持已登录条件。AuditPanel默认调用无date参数由服务端给北京时间日期，日期选择格式YYYY-MM-DD；page/size和取消迟到响应版本号驻组件。表显示时间、动作、对象、结果，详情展示结构化changes，不渲染HTML。empty与warnings/error明确分开。
api.getAudit使用URLSearchParams构造参数，不拼接任意文件名。
call非2xx沿现有error提取，但新增导出ManagementAPIError extends Error携带可选audit:AuditMeta；这是保存入口需要显示“业务失败且审计失败”的接口，不能丢弃错误响应中的audit。
StateResponse及名称返回类型增加可选audit。RulesPanel/KeysPanel保存处理：先按业务结果onSaved/保留输入，再分别提示audit警告；POST更名+DELETE两次各自警告不得被最后响应吞掉。错误响应既显示原error也显示audit问题。Keeper unknown的独立文案沿T05。
名称编辑器的catch也按结构读取可选error.audit，已有后端返回的非2xx若带审计失败信息不能被普通Error.message吞掉；补真实组件回归，保持无audit的Begin503只显示原错误、不伪造操作结果。
不新增后台自动刷新；提供主动刷新和分页。CSS在窄屏使用表格容器滚动，页面本身不横向溢出。
