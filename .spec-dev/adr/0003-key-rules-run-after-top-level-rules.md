# ADR-0003: key 规则集串联跑在顶层规则之后

- 日期：2026-07-25
- 状态：已接受

## 背景

key 专属规则与既有顶层规则（端点段/global_rules，端点非空整组取代全局、不叠加）需要叠加语义。

## 决定

key 规则集串联跑在顶层规则输出之后：先执行顶层规则集得 M₁，再对该 key 规则集中按端点选中的段接力执行得 M₂；M₂ 等于原始模型时不接管路由。key 规则集内部段选择（端点段非空用端点段、留空回退该 key 全局段）与顶层同构。

## 理由

用户裁决。接力语义下 key 永远有最终话语权，"推翻端点结果""逐 key 再降档"等场景有自然表达，且段选择逻辑可整体复用。被否方案：key 规则整组取代顶层规则（丢失顶层通用映射）；key 规则跑在顶层之前（顶层规则会覆盖 key 的定向调整）。
