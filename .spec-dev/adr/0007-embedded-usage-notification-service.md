# ADR-0007: 将用量通知服务内置于 mapper 插件

**Status**: Accepted (2026-09-13)

## 背景

用量通知需要定时采集 Keeper 数据、保存跨重启任务并向三个平台发送消息。当前产品以单个 c-shared mapper 插件部署，没有通知进程或任务服务。

## 决定

将通知生命周期、统计快照、任务调度和平台发送内置于 mapper 插件，并使用独立的 bbolt 运行库保存任务与快照；Keeper 保持只读数据源，平台适配器留在 mapper 内。

## 理由

内置服务复用现有管理鉴权、重配和插件分发方式，部署边界最小；bbolt 提供单文件、事务、进程锁和纯 Go 嵌入能力，适合任务状态和历史快照，不需要额外数据库服务。独立通知进程虽然隔离故障，但会增加进程通信、部署和状态一致性边界。
