# T05：CI、文档与构建

**依赖**：T04
**文件**：修改 .github/workflows/build.yml、README.md、CLAUDE.md；构建 web/dist/index.html
**接口**：消费 实现及测试；产出 CI、配置文档、web/dist/index.html。

**步骤 1：失败测试 / 前置检查**

检查 CI 现状和已有依赖，沿用当前构建链；无需为配置/文档写镜像测试。

**步骤 2：确认失败 / 执行前置动作**

```bash
npm --prefix web run typecheck
npm --prefix web test
```

实现任务预期首次因对应新功能缺失而失败；T00/T05/T06/T07 属环境/验证任务。

**步骤 3：实现 / 执行动作**

CI 增加前端类型和测试；文档写清 YAML/环境变量/同步保存区别及故障；make web-build 生成嵌入页。

**步骤 4：验证**

```bash
go test ./...
go vet ./...
make web-build
go test .github/scripts/package-release.go .github/scripts/package-release_test.go
git diff --check
```

预期：完整自动验证通过；生成前端与源码一致。

**步骤 5：记录结果与提交边界**

更新 progress.yaml、记录测试证据和本任务差异。单独提交指示到来后再提交；当前不提交或推送。对照 spec 自检覆盖与接口一致性。
