# T07：交付与清理

**依赖**：T06
**文件**：更新 progress.yaml、acceptance-report.md；集成实现变更
**接口**：消费 审查/验收结论；产出 完整交付记录和用户可用工作区。

**步骤 1：失败测试 / 前置检查**

检查主工作区有无新改动，保证用户内容不被覆盖；确认全量验证结果。

**步骤 2：确认失败 / 执行前置动作**

```bash
git diff --check
```

实现任务预期首次因对应新功能缺失而失败；T00/T05/T06/T07 属环境/验证任务。

**步骤 3：实现 / 执行动作**

按用户提交授权集成：无提交授权则复制已验证变更回主工作区并保留为未提交；不推送。仅清理本次登记的测试资源和已安全移交的 worktree。

**步骤 4：验证**

```bash
git status --short
```

预期：用户主工作区得到全部已验证变更；资源清理可追溯；如无提交，sync_commit 保持 null。

**步骤 5：记录结果与提交边界**

更新 progress.yaml、记录测试证据和本任务差异。单独提交指示到来后再提交；当前不提交或推送。对照 spec 自检覆盖与接口一致性。
