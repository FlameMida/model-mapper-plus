### 任务 4：消息指标分行

**文件**：
- 修改：`notification_template.go:104-115`
- 测试：`notification_template_test.go`

**接口**：
- 消费：`renderMessage(n Notification, d statsData, now time.Time) (string, renderWarnings)`
- 产出：同一函数；渠道块格式为展示名独占一行，随后 `用量 … tokens` / `占比 …` 或 `占比未知` / 可选 `折算 ≈ $…` 各一行。全局 `statsData.Channels` 仅一行时窗口只渲染该 identity 的 quota。

**步骤 1：写失败测试**

`TestPeriodChannelMetricsEachOnOwnLine`：日统计一条渠道 → 文本含 `"Codex\n"` 后接 `"用量 800.00K tokens\n"`，同一行不得同时含 `tokens` 与 `%`（Scenario：周期渠道分行）。
`TestClosedModulesLeaveNoBlankPlaceholder`：只开日统计 → 无「年统计」标题（既有模块勾选 Scenario）。

**步骤 2：运行确认失败**

运行：`go test . -count=1 -run '^TestPeriodChannelMetricsEachOnOwnLine$'`
预期：旧实现 `fmt.Fprintf(..., "%s：%s tokens · ", ...)` 导致 FAIL。

**步骤 3：写最小实现**

替换渠道循环为：

```go
fmt.Fprintf(&b, "%s\n", ch.Label)
fmt.Fprintf(&b, "用量 %s tokens\n", abbreviateTokens(ch.Tokens))
if ch.ShareKnown {
    fmt.Fprintf(&b, "占比 %.2f%%\n", ch.Share*100)
} else {
    fmt.Fprintf(&b, "占比%s\n", msgUnknownShare)
}
if ch.CostAvailable {
    fmt.Fprintf(&b, "折算 ≈ $%.2f\n", ch.CostUSD)
}
```

窗口行同样拆成已用 / 重置 / 还剩各一行。全局 enqueue 只把该渠道放入 `statsData.Channels`。

**步骤 4：运行确认通过**

`go test . -count=1 -run '^Test(PeriodChannel|Render|Collect)'` 预期 PASS。
