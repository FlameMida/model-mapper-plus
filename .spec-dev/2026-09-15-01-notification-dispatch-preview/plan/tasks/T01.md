**步骤 1：写失败测试**

`TestDueAtIntervalSecondBeat`：lastSuccess=T，interval=60s，now=T+60s → due=true，next=T+60s。
`TestDueAtIntervalDoesNotSlideWithPoll`：lastSuccess=T，now=T+15s → due=false，next=T+24h（interval=86400）。
`TestDueAtMonthlyCatchupLatestOnly`：month-start 09:00，lastSuccess 早于上月月初，now 已过本月月初 → due=true 且只对应本月该点。
`TestFormatNextFireHumanCST`：`2026-09-15T08:44:47+08:00` → `"2026-09-15 08:44:47"`，不得含 `T` 或 `+08:00`。
`TestUpsertJobDoesNotMergeDifferentChannels`：同一 nid/platform/periodKey，Channel `a` 与 `b` → store 两条 pending。

**步骤 3：写最小实现**

```go
func formatNextFire(t time.Time) string {
    if t.IsZero() { return "" }
    return t.In(NotificationLocation).Format("2006-01-02 15:04:05")
}
```

`dueAt`：interval 且 lastSuccess.IsZero() → due=true, next=now；interval 且 now.Sub(lastSuccess)>=interval → due=true, next=now（只补最近一次，不补中间间隔）；否则 next=lastSuccess+interval。monthly/yearly：`cand, ok := nextTrigger(sched, lastSuccess, loc)`，若 cand.After(now) 则 due=false, next=cand；否则 due=true, next=cand（该 cand 即最近已过点；lastSuccess 已过该点则 nextTrigger 会给出更晚点）。
