# 定向凭据冷却 Live 验收

- 结果：**DEFERRED / UNVERIFIED**

当前独立 CPA 中只有一个可用 auth 文件，它的实际上游状态是计费周期额度耗尽（HTTP 403），不是可安全制造并恢复的宿主 cooldown。按计划约束，未伪造 429，也未改写生产凭据状态。

代码审查与独立复核另外确认了一个契约问题：当“目标池凭据冷却，但池外存在 active 凭据”时，宿主会先全局过滤再调用 Scheduler，插件只能看到池外候选；过滤后池为空将返回 503，无法保证计划中的原生 429 `model_cooldown` + `Retry-After`。该发现需设计裁决或宿主接口支持。

恢复状态：未修改任何凭据文件或 cooldown 状态。
