消息正文风格：同一份数据，三种排版（点选其一）

三平台的最大公约数是行式文本（企微/钉钉 markdown 均不支持表格），所以比的是排版风格而非组件。 三个版本用同一组数据：渠道明细（Token K/M/B 缩写 + 占比 + USD 折算）、占比未知、历史缺失标注、Weekly 窗口、重置卡。 spec 硬性口径已内嵌：占比未知不显示 0%、缺失日期明确标注、金额标注为折算。
