⠿ ✓ 日统计 本期累计 ▾

按住 ⠿ 拖动整行换位，一步到位；灰色行不可拖。

A · 行式上下移：零新增依赖（现仓库只有 semi-ui / semi-icons）；键盘可达、jsdom 行为测试直接。缺点是模块多时连续点按稍繁琐。
B · 拖拽排序：调整顺序最直观。但 Semi 没有 SortableList，需要新增 dnd-kit 依赖，且拖拽行为在 jsdom 里难以测真、单文件 UI 体积也会增大。

发送计划：三种周期类型的字段（随「周期类型」Select 切换）

周期类型出现的字段组件
每隔间隔值 + 单位（秒 / 分 / 时 / 天）InputNumber + Select
每月月初 / 月末 + 发送时间Select + TimePicker（HH:mm:ss）
每年月份 + 日期 + 发送时间（2月29日在非闰年跳过并提示下一次有效时间）Select + Select + TimePicker（HH:mm:ss）

已按 spec 固化的口径：日历定时只有 每隔 / 每月 / 每年 三类（无每天、每周）；每月只能选月初或月末；时间一律秒级 TimePicker。 计划留空时回退全局默认计划。
