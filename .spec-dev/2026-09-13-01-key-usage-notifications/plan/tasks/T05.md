真实 Keeper 契约（已核对 `/Users/maverick/cpa-usage-keeper/internal/api/usage_overview.go`、`usage_analysis.go:151`、`quota.go`）：
- `GET /api/v1/usage/overview` → `{usage:{total_tokens}, summary:{total_cost, cost_available}, timezone}`；时间过滤 query 参数名以 `parseUsageFilterQuery`（usage_filter.go）为准，执行时先 grep 确认再写构造（预期 `start`/`end` RFC3339；若不同就地修正注明，属小偏差）。
- `GET /api/v1/usage/analysis` → `api_key_composition[]`：`{key, label, total_tokens, percent, cost_usd, cost_available}`——分母 = 本周期该项 `total_tokens` 之和。
- `POST /api/v1/quota/cache` body `{"auth_indexes":[...]}` → 条目含 `key/plan/tierName/groupKey/windowUsageTokens/windowUsageCost/resetAt/credits/availableCount`（`internal/quota/types.go`）；`groupKey` 区分 5H/Weekly。
- `GET /api/v1/quota/reset-credits/:auth_index` → `availableCount`、`credits[]`。
- Key 消耗取法：若 keeper 的 overview/analysis 过滤参数不支持按 api key 过滤，则 Key 消耗 = analysis 中该 key 的 `total_tokens`，分母 = 全部项之和（两种取法都满足 spec 占比定义；替身测试按后者写死，执行时以 usage_filter.go 过滤参数为准）。

**步骤 3：写最小实现**

`notification_keeper.go` 结构与关键函数：

```go
package main

import (
	"context"
	"encoding/json"
	"net/http"
	"strings"
	"time"
)

type keeperStatsSource struct {
	client *keeperClient
	now    func() time.Time
}

func newKeeperStatsSource(cfg Config) (*keeperStatsSource, string) {
	if strings.TrimSpace(cfg.UsageKeeperURL) == "" {
		return nil, "" // 通知服务上层转 disabled 语义
	}
	client, err := newKeeperClient(cfg.UsageKeeperURL, cfg.UsageKeeperPasswordEnv)
	if err != nil {
		return nil, "configuration_error"
	}
	return &keeperStatsSource{client: client, now: time.Now}, ""
}

type analysisItem struct {
	Key, Label    string
	TotalTokens   int64
	CostUSD       float64
	CostAvailable bool
}

// channelShares：分母 = 各项 total_tokens 之和；total>0 才 ok（spec 分母为零 → 占比未知）。
func channelShares(items []analysisItem) (int64, bool) {
	var total int64
	for _, it := range items {
		total += it.TotalTokens
	}
	return total, total > 0
}

// collectForPeriod：periodRange(T03) 取窗口 → fetchAnalysis 取渠道组成 → 逐项换算
// share（total>0 时 = tokens/total，否则 ShareKnown=false）→ periodStats{Start, End, PeriodKey, Channels}。
func (s *keeperStatsSource) collectForPeriod(ctx context.Context, apiKey string, kind ModuleKind, period PeriodKind, now time.Time) (periodStats, error) {
	start, end, ok := periodRange(kind, period, now, NotificationLocation)
	if !ok {
		return periodStats{}, &keeperError{Code: "invalid_response"}
	}
	items, err := s.fetchAnalysis(ctx, start, end)
	if err != nil {
		return periodStats{}, err
	}
	stats := periodStats{Start: start, End: end, PeriodKey: periodKeyOf(kind, period, now), Channels: []channelStats{}}
	total, _ := channelShares(items)
	for _, it := range items {
		cs := channelStats{Name: it.Key, Label: it.Label, Tokens: it.TotalTokens,
			CostUSD: it.CostUSD, CostAvailable: it.CostAvailable, ShareKnown: total > 0}
		if total > 0 {
			cs.Share = float64(it.TotalTokens) / float64(total)
		}
		stats.Channels = append(stats.Channels, cs)
	}
	return stats, nil
}
```

`fetchAnalysis`：路径 `/api/v1/usage/analysis` + 时间过滤 query（参数名以 `/Users/maverick/cpa-usage-keeper/internal/api/usage_filter.go` 的 `parseUsageFilterQuery` 为准，预期 `start`/`end` RFC3339 UTC；不同就地修正注明）→ `s.client.authenticatedRequest(ctx, http.MethodGet, path, nil)` → 非 200 走 `keeperHTTPError(resp)`（封闭码）→ `readKeeperBody` → `parseAnalysisComposition(raw)`。

`parseAnalysisComposition(raw)`：`json.Unmarshal` 到含 `api_key_composition []struct` 的匿名结构（字段带指针：`key`/`label`/`total_tokens`/`cost_usd`/`cost_available`）；`Unmarshal` 失败或 `Composition == nil` → `&keeperError{Code: "invalid_response"}`；逐行 `key`/`total_tokens` 为 nil → 同样 `invalid_response`，其余字段 nil 安全拷贝；返回 `[]analysisItem`。字段 JSON 名以契约 bullet 为准（`internal/api/usage_analysis.go` 已核对）。

`collectWindows(ctx, authIndexes, now)`：POST `/api/v1/quota/cache` body `{"auth_indexes":[...]}`；解析顶层 `items`（以 `/Users/maverick/cpa-usage-keeper/internal/quota/types.go` 的 `CacheResponse` 为准）：`groupKey` 小写归一为 `5h`/`weekly`，其余丢弃（spec：不存在的窗口不渲染）；`windowUsageTokens` nil → `WindowUsageAvailable=false`；`resetAt` 解析成功 → `ResetKnown=true` 并按 now 差值算 `RemainingDays/RemainingHours`（向下取整）；`tierName` 优先、缺省回 `plan`，皆空 → `""`（渲染层显示「未知/未提供」）；`availableCount` nil → `ResetCards=nil`。`GET /quota/reset-credits/:auth_index` 作为 availableCount 补充来源（cache 条目缺 credits 时）。传输错误统一经 `keeperHTTPError` 保持封闭码。

`periodKeyOf(kind, period, now)`（T06 依赖）：`"daily:2026-09-13"` / `"monthly:2026-09"` / `"half:2026H2"` / `"yearly:2026"` + 上一周期加 `":prev"` 后缀（合并判重维度——spec：不同统计周期任务不合并；interval 类由 T08 用触发锚点拼接）。
