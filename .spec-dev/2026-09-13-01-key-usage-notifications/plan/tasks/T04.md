**接口**：
- 消费：T02 的 `PlatformKind`
- 产出（T08/T09 依赖的精确签名）：
  - `type notificationJob struct { ID, KeyFingerprint, NotificationID string; Platform PlatformKind; PeriodKey string; State string; Payload []byte; MergedCount int; Attempts int; Revision uint64; NextAttempt, CreatedAt, UpdatedAt time.Time }`（State ∈ `jobPending/jobSending/jobSent/jobFailed/jobUnknown/jobSuperseded`；Revision = 入队时 store.Revision，供 T08 热重配丢弃过期任务）
  - `type deliveryRecord struct { ID, JobID, KeyFingerprint, NotificationID string; Platform PlatformKind; PeriodKey, Outcome, ErrorCode, Detail string; CreatedAt time.Time }`（Outcome ∈ `deliveryAccepted/deliveryFailed/deliveryUnknown`）
  - `type snapshotRecord struct { KeyFingerprint, AuthIndex, Channel, PeriodKey string; Tokens int64; CostUSD float64; CostAvailable bool; Plan string; ResetCards *int; CoverageStart, CoverageEnd, FetchedAt string; Incomplete bool }`
  - `func keyFingerprint(key string) string`（SHA-256 前 16 hex）
  - `func openNotificationStore(path string) (*notificationStore, error)`
  - `(*notificationStore).Close() error`；`Revision() uint64`；`BumpRevision() (uint64, error)`
  - `UpsertJob(j notificationJob) (merged int, err error)`——同 (KeyFingerprint,NotificationID,Platform,PeriodKey) 已有 pending 任务时：更新 Payload/NextAttempt、`MergedCount+1`，返回合并后计数
  - `ClaimDueJobs(now time.Time, limit int) ([]notificationJob, error)`（pending && NextAttempt<=now → 置 sending，同事务返回）
  - `FinishJob(id, outcome, errCode, detail string) error`（sending → 终态 + 同事务写 deliveryRecord）
  - `RecoverOnBoot() error`（所有 sending → unknown，各写一条 unknown 投递记录）
  - `Deliveries(f DeliveryFilter) ([]deliveryRecord, error)`（`type DeliveryFilter struct { KeyFingerprint, NotificationID string; Platform PlatformKind; Outcome string; Limit int }`，零值字段不过滤）
  - `PutSnapshots(key string, rows []snapshotRecord) error` / `SnapshotsFor(keyFingerprint, periodKeyPrefix string) ([]snapshotRecord, error)`
  - bucket：`config_revision`、`jobs`、`deliveries`、`snapshots`（key = fingerprint/periodKey/seq）

func TestUpsertJobMergesSamePeriodPending(t *testing.T) {
	s := openTestStore(t)
	now := time.Now()
	base := notificationJob{ID: "j1", KeyFingerprint: "fp1", NotificationID: "global",
		Platform: PlatformFeishu, PeriodKey: "daily:2026-09-13", State: jobPending,
		Payload: []byte("v1"), NextAttempt: now, CreatedAt: now}
	if _, err := s.UpsertJob(base); err != nil { t.Fatalf("upsert1: %v", err) }
	later := base
	later.ID = "j2"
	later.Payload = []byte("v2-latest")
	merged, err := s.UpsertJob(later)
	if err != nil { t.Fatalf("upsert2: %v", err) }
	if merged != 2 { t.Fatalf("want merged count 2, got %d", merged) }
	due, _ := s.ClaimDueJobs(now.Add(time.Minute), 10)
	if len(due) != 1 || string(due[0].Payload) != "v2-latest" || due[0].MergedCount != 2 {
		t.Fatalf("want single latest job, got %+v", due)
	}
}

func TestDifferentPeriodJobsDoNotMerge(t *testing.T) {
	s := openTestStore(t)
	now := time.Now()
	a := notificationJob{ID: "a", KeyFingerprint: "fp", NotificationID: "n", Platform: PlatformFeishu, PeriodKey: "daily:2026-09-13", State: jobPending, NextAttempt: now, CreatedAt: now}
	b := a
	b.ID = "b"
	b.PeriodKey = "daily:2026-09-14"
	if _, err := s.UpsertJob(a); err != nil { t.Fatal(err) }
	if _, err := s.UpsertJob(b); err != nil { t.Fatal(err) }
	due, _ := s.ClaimDueJobs(now.Add(time.Minute), 10)
	if len(due) != 2 { t.Fatalf("different periods must not merge, got %d", len(due)) }
}

func TestRecoverOnBootMarksSendingUnknown(t *testing.T) {
	s := openTestStore(t)
	now := time.Now()
	j := notificationJob{ID: "j", KeyFingerprint: "fp", NotificationID: "n", Platform: PlatformFeishu, PeriodKey: "p", State: jobPending, NextAttempt: now, CreatedAt: now}
	s.UpsertJob(j)
	due, _ := s.ClaimDueJobs(now.Add(time.Minute), 10)

	if err != nil || len(rows) != 1 || rows[0].Outcome != deliveryUnknown {
		t.Fatalf("want unknown delivery after recover, got %v %v", rows, err)
	}

**步骤 3：写最小实现**

`notification_store.go` 实现要点（bucket 常量与序列化口径先定，关键片段随后）：

```go
package main

import (
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"fmt"
	"time"

	bolt "go.etcd.io/bbolt"
)

const (
	jobPending    = "pending"
	jobSending    = "sending"
	jobSent       = "sent"
	jobFailed     = "failed"
	jobUnknown    = "unknown"
	jobSuperseded = "superseded"

	deliveryAccepted = "accepted"
	deliveryFailed   = "failed"
	deliveryUnknown  = "unknown"
)

var (
	bucketRevision   = []byte("config_revision")
	bucketJobs       = []byte("jobs")
	bucketDeliveries = []byte("deliveries")
	bucketSnapshots  = []byte("snapshots")
)

func keyFingerprint(key string) string {
	sum := sha256.Sum256([]byte(key))
	return hex.EncodeToString(sum[:])[:16]
}

type notificationStore struct{ db *bolt.DB }
```

- `openNotificationStore(path)`：`bolt.Open(path, 0o600, &bolt.Options{Timeout: 3*time.Second})`（文件锁冲突在 3s 后报错 → T08 转受控 unavailable）；随后 `db.Update` `CreateBucketIfNotExists` 四个 bucket。
- `Revision()`/`BumpRevision()`：`config_revision` bucket 的 `"revision"` key 存 8 字节大端 uint64；Bump 在 `db.Update` 内读加写。
- 合并维度 key：`jobKey(j) = j.KeyFingerprint + "/" + j.NotificationID + "/" + string(j.Platform) + "/" + j.PeriodKey`——UpsertJob 的 Get/ Put 都用同一前缀，判重天然落库。
- `UpsertJob(j) (merged int, err error)`（合并核心，`db.Update` 内）：

```go
		if raw := b.Get(jobKey(j)); raw != nil {
			var existing notificationJob
			if json.Unmarshal(raw, &existing) == nil && existing.State == jobPending {
				existing.Payload = j.Payload
				existing.NextAttempt = j.NextAttempt
				existing.MergedCount++
				existing.UpdatedAt = time.Now().UTC()
				merged = existing.MergedCount
				updated, err := json.Marshal(existing)
				if err != nil {
					return err
				}
				return b.Put(jobKey(j), updated)
			}
		}
		j.MergedCount = 1
		j.UpdatedAt = time.Now().UTC()
		merged = 1
		// json.Marshal + b.Put(jobKey(j), raw)
```

- `ClaimDueJobs(now, limit)`：`db.Update` + `b.ForEach`，命中 `State==jobPending && !NextAttempt.After(now)` 的任务置 sending 后 `b.Put` 同 key，收集返回（limit 截断）。
- `FinishJob(id, outcome, errCode, detail)`：`db.Update` 内游标找到 `ID==id` 的任务 → 终态回写 + 同事务向 `deliveries` bucket 追加 `deliveryRecord`（key = `CreatedAt.UTC().Format("20060102150405.000000000")+"/"+rec.ID`；`Detail` 只放受控描述与错误码，不放响应体/webhook——全局约束）；找不到 → `fmt.Errorf("job %s not found", id)`。
- `RecoverOnBoot()`：`db.Update` 内游标收集全部 `State==jobSending` → 逐个置 `jobUnknown` 回写 + 各写一条 `{Outcome: deliveryUnknown, ErrorCode: "restart_during_send"}` 投递记录（spec 重启恢复 Scenario）。
- `Deliveries(f DeliveryFilter)`：`db.View` 游标**从尾向前**（新→旧），按 filter 非零字段过滤，`Limit` 截断。
- `PutSnapshots(key, rows)`/`SnapshotsFor(fingerprint, periodKeyPrefix)`：snapshots bucket key = `fingerprint + "/" + periodKey + "/" + seq(UnixNano)`；查询用 cursor prefix 扫描。
- delivery/record ID 格式：`fmt.Sprintf("%d-%s", UnixNano, jobID)`、恢复记录 `recover-<jobID>`。
