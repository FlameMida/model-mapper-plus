**接口**：

- 产出：
  - `type statsData struct { DisplayName, Plan string; Periods map[string]periodStats; Windows []windowStat; ResetCards *int }`

**步骤 3：写最小实现**

```go
package main

import (
	"fmt"
	"strings"
	"time"
)

const (
	msgUnknownPlan  = "未知/未提供"
	msgUnknownShare = "占比未知"
	msgAmountNote   = "金额为 Keeper 价格折算，非上游账单"
)

type statsData struct {
	DisplayName string
	Plan        string
	Periods     map[string]periodStats
	Windows     []windowStat
	ResetCards  *int
}

type renderWarnings struct{ Incomplete []string }

func abbreviateTokens(n int64) string {
	switch {
	case n >= 1_000_000_000:
		return fmt.Sprintf("%.2fB", float64(n)/1e9)
	case n >= 1_000_000:
		return fmt.Sprintf("%.2fM", float64(n)/1e6)
	case n >= 1_000:
		return fmt.Sprintf("%.2fK", float64(n)/1e3)
	default:
		return fmt.Sprintf("%d", n)
	}
}

var moduleHead = map[ModuleKind]string{
	ModuleDaily: "日统计", ModuleMonthly: "月统计",
	ModuleHalfYear: "半年统计", ModuleYearly: "年统计",
}
```

`renderMessage(n, d, now)` 组装顺序（`strings.Builder`）：

1. 标题行 `n.Name`；第二行 `DisplayName（空 → msgUnknownPlan） · Plan（空 → msgUnknownPlan）`，随后空行。
2. 依 `n.Modules` 顺序逐模块：
   - 统计周期模块：`periodRange`（T03）取窗口；`d.Periods[periodKeyOf(...)]`（T05）取数据，缺失则跳过整节；节标题 `▍日统计 · 本期累计（2006-01-02 ~ 2006-01-02）`（scope：`previous` → `上一完整周期`）；渠道行 `Label：{缩写} tokens · {share|msgUnknownShare}`，`CostAvailable` 时追加 ` · ≈$%.2f`；`ps.Incomplete` 时追加 `⚠ {MissingFrom}~{MissingTo} 历史数据不完整` 行并记入 `warn.Incomplete`；节尾空行。
   - `weekly`/`window_5h`：在 `d.Windows` 中按 `GroupKey`（小写）匹配，无匹配不渲染（spec Scenario）；节标题 `▍Weekly 窗口`/`▍5H 窗口`；`WindowUsageAvailable` → `已用 {缩写} tokens` 行；`ResetKnown` → `{resetAt 格式 2006-01-02 15:04} 重置 · 还剩 {RemainingDays} 天 {RemainingHours} 小时`。
   - `reset_cards`：`d.ResetCards == nil` → 不渲染（未提供；明确的 0 渲染为 0 张）；否则 `▍重置卡（N 张）`。
3. 末尾 `msgAmountNote`；整体 `TrimRight "\n"` 返回。
