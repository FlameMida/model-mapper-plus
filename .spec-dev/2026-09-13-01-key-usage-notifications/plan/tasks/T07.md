### 任务 7：三平台适配器

**文件**：
- 创建：`notification_platform.go`（接口 + 工厂 + 拆分）、`notification_platform_wecom.go`、`notification_platform_feishu.go`、`notification_platform_dingtalk.go`
- 测试：`notification_platform_test.go`

**接口**：
- 消费：T02 `PlatformIdentity`/`PlatformKind`
- 产出：
  - `type outboundMessage struct { Title, Body string; UserIDs []string }`
  - `type deliveryResult struct { Outcome, ErrorCode, Detail string; RetryAfter time.Duration }`（Outcome 取 T04 的 `deliveryAccepted/deliveryFailed/deliveryUnknown`）
  - `type platformAdapter interface { send(ctx context.Context, msg outboundMessage) ([]deliveryResult, error) }`（返回切片 = 拆分后每片一条结果）
  - `func buildAdapter(p PlatformIdentity) (platformAdapter, error)`（http.Client 超时 10s）
  - `func splitMessage(body string, limit int) []string`（按 "\n\n" 节边界贪心打包；单节超限硬切）

平台契约（官方文档口径，spec 已登记平台限制）：
- 企业微信：POST `{webhook}` body `{"msgtype":"markdown","markdown":{"content":...,"mentioned_list":[...]}}`；HTTP 200 但 `errcode!=0` = 业务失败；无加签；markdown 4096 字节。
- 飞书：POST `{webhook}`（开启签名校验时加 `timestamp` + `sign`：`sign = base64(hmac_sha256(key=secret, data=timestamp+"\n"+secret))`，字段放 body `{"timestamp":"...","sign":"..."}`）；`{"msg_type":"text","content":{"text":...}}`，@ 用文本前缀 `<at user_id="ou_x"></at>`；`code!=0` = 业务失败；30KB。
- 钉钉：POST `{webhook}&timestamp=ms&sign=urlencode(base64(hmac_sha256(key=secret, data=ms+"\n"+secret)))`；body `{"msgtype":"markdown","markdown":{"title":...,"text":...},"at":{"atUserIds":[...]}}`；`errcode!=0` = 业务失败；20000 字节。

`notification_platform.go`：类型 `outboundMessage`/`deliveryResult`/`platformAdapter` 按接口块定义（`send` 返回切片 = 拆分后每片一条结果；`http.Client` 超时 10s）。`buildAdapter(p)`：按 `p.Kind` switch 返回对应 adapter（wecom/feishu/dingtalk），未知 kind → `&keeperError{Code: "configuration_error"}`。

平台字节上限（全局约束；spec 矩阵行"字节限制和拆分"）：`wecomMarkdownLimit = 4096`、`dingtalkMarkdownLimit = 20000`、`feishuTextLimit = 30 << 10`。

`splitMessage(body, limit)`（可测核心，按 "\n\n" 节边界贪心打包；单节超限硬切）：

```go
func splitMessage(body string, limit int) []string {
	if len(body) <= limit {
		return []string{body}
	}
	var parts []string
	current := ""
	for _, section := range strings.Split(body, "\n\n") {
		for len(section) > limit { // 单节超限硬切
			if current != "" { parts = append(parts, current); current = "" }
			parts = append(parts, section[:limit])
			section = section[limit:]
		}
		candidate := section
		if current != "" { candidate = current + "\n\n" + section }
		if len(candidate) > limit {
			parts = append(parts, current)
			current = section
		} else {
			current = candidate
		}
	}
	if current != "" { parts = append(parts, current) }
	return parts
}
```

`notification_platform_wecom.go`：`send` 对每片 POST `{"msgtype":"markdown","markdown":{"content":片,"mentioned_list":userIDs}}`；解析 `{"errcode":0}`；`errcode!=0` → `deliveryFailed`（ErrorCode `"wecom_errcode"`，Detail 含 errcode 数值，不含响应体全文）；429 → `rate_limited` + Retry-After；超时/传输错误 → `deliveryUnknown`（`"transport_unknown"`——HTTP 结果未知，spec 不伪造）。**不发送任何签名**（spec：企微无加签）。

`notification_platform_feishu.go`：`secret != ""` 时 body 顶层加 `"timestamp"`（Unix 秒字符串）与 `"sign"`：

```go
func feishuSign(secret string, ts int64) string {
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(strconv.FormatInt(ts, 10) + "\n" + secret))
	return base64.StdEncoding.EncodeToString(mac.Sum(nil))
}
```

body `{"timestamp":...,"sign":...,"msg_type":"text","content":{"text":atPrefix+片}}`，`atPrefix = "<at user_id=\"ou_x\"></at> "` 逐个拼接（仅 `strings.HasPrefix(id, "ou_")` 的 ID 内联 @，其余附加到文本末尾列表——外部群仅 Open ID，spec）；`code!=0` → failed；30KB 上限用 `feishuTextLimit`。

`notification_platform_dingtalk.go`：URL 附加 `&timestamp=<ms>&sign=<url.QueryEscape(base64(hmac-sha256(secret, ms+"\n"+secret)))>`（secret 为空则不加）；body `{"msgtype":"markdown","markdown":{"title":Title,"text":片},"at":{"atUserIds":userIDs}}`；`errcode!=0` → failed；429 → rate_limited；20000 上限用 `dingtalkMarkdownLimit`。

三适配器共用辅助：`postJSON(ctx, url, body any) (statusCode int, respBody []byte, err error)`（放 notification_platform.go，所有 Detail/错误构造不包含 webhook URL 与响应体原文——closed error codes 全局约束）。
