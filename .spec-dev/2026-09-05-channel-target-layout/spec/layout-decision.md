# 渠道定向布局定稿：B

确认日期：2026-09-05。用户选择 B，并在接口调研后明确收敛范围：「不联动 CPA，舍弃 AI Providers 功能，转为 quick-fix，仅应用 B 版布局修改」。此裁决取代此前两类来源接入方案。

## 本次范围

- 保留绑定编辑弹窗的「基础 / 渠道定向 / 规则集」三页。
- 渠道定向使用左侧供应商导航、右侧认证文件列表；窄屏改为顶部横向供应商导航。
- 数据仍读取现有 auth-files，保存仍使用 `suppliers` 与 `auth_ids`，调度逻辑保持现状。
- 右侧提供供应商整选、文件名称/ID 搜索、当前结果全选、每项状态与整选覆盖提示。
- 搜索后的批选只增删可见结果，保留跨供应商、筛选外及暂未返回的已选 ID。切换供应商清空搜索，保留所有选择。
- 总开关关闭时选择与搜索禁用，配置保留；仍可切换供应商查看。
- 加载图标与「正在加载认证文件…」同一行展示。
- 加载失败展示「认证文件加载失败，已选配置已保留。」、错误详情与「重新加载」，文字统一为 14px。

## 契约同步

修改现行 [渠道定向 spec](../../2026-08-22-channel-target-and-fast-control/spec/channel-target-and-fast-control-design.md) 的 Admin UI Requirement 与对应 Scenario，采用 quick-fix 的契约同步分支。AI Providers 接入、CPA 宿主改动、SDK 改动及 ID 映射方案均已取消。
